# 🎮 Hangman Game (CodeAlpha Python Internship)

A clean, interactive text-based Hangman game built using Python.

## 📌 Features
- Random word selection from a curated word bank.
- Tracks guessed letters and prevents duplicate entries.
- Real-time display of attempts remaining.

## 🛠️ Built With
- **Language:** Python 3

## ⚙️ How to Run
1. Clone or download this repository.
2. Open your terminal or command prompt in the project folder.
3. Run the script:
   ```bash
   python main.py
